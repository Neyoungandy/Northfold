# Northfold Stoneware Mug

Product page for Northfold's first piece: a $28 stoneware mug in Oat, Slate, and Moss. One HTML file and one CSS file, no libraries.

Gallery, glaze radios, quantity, and add to cart sit in the product block. Three short benefits sit underneath. Layout is one column under 750px and two columns above.

I switched the photos with radio buttons and CSS `:has()` instead of JavaScript. The brief only allowed HTML and CSS, and this still lets someone keyboard through the shots.
